# Monedín para menores de 5 años

Juego educativo sin internet para aprender las monedas chilenas ($10, $50, $100, $500). 3 misiones de 2 etapas; las preguntas cambian en cada partida.

**En iPhone/iPad:** abrir en Safari, tocar Compartir y «Agregar a pantalla de inicio». Se abre a pantalla completa y funciona sin conexión.

Presentación de Pensamiento Matemático: Livier Alarcón, Betsabe Belmar, María Venegas, Johanna Paredes.
Imágenes de las monedas: Banco Central de Chile (uso educativo permitido).
